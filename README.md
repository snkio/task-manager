## 🛠️ Tech Stack

- React  
- JavaScript  
- Tailwind CSS
    
## 💫 Features

- **Create tasks:** add new tasks to the list
- **Edit tasks:** edit existing tasks in the list
- **Delete tasks:** remove tasks from the list
- **Task filtering:** filter tasks by status (All/Active/Completed)
- **Data persistence:** saving tasks in localStorage
    

## 🌐 Getting Started
### Installation

```bash
git clone https://github.com/snkio/task-manager.git
cd task-manager
npm install
```

### Running locally

```bash
npm run dev
```
